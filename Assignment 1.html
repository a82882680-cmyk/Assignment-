Assignment 1 – What happens between typing a URL and seeing the page?When I type a URL into the browser and press Enter, the browser first checks its cache and then asks a DNS server to translate the domain name (e.g., example.com) into an IP address. It then opens a TCP connection to that server (and, for HTTPS, performs a TLS handshake to encrypt the traffic) and sends an HTTP request, such as GET /index.html. The server processes the request and replies with an HTTP status code (e.g., 200 OK) along with the HTML document. The browser parses the HTML into the Document Object Model (DOM), discovers extra resources (like CSS, JavaScript, images, and fonts) and requests them too. It builds the CSSOM from the CSS, combines both the DOM and CSSOM into a Render Tree, calculates the Layout (geometry of elements), Paints the pixels to the screen, and finally runs JavaScript to make the page interactive.
