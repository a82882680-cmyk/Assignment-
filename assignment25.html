Design Choices

Colour: deep blue gives a calm, professional look, and the orange accent is used only on buttons so users find actions quickly.

Typography: a system font stack loads fast, and a line-height of 1.6 keeps paragraphs easy to read.

Layout: content is limited to 800px so lines stay comfortable to read, and white cards on a light-grey background create depth.

Maintainability: colours are stored in CSS variables, so the whole theme can be changed in one place.
