Calculation (default box-sizing: content-box)

Total width 220 + (24×2) + (8×2) = 284px (+56px margin = 340px of horizontal space)
Total height 90 + (24×2) + (8×2) = 154px (+56px margin = 210px)

With box-sizing: border-box

The same width: 220px would already include padding and border, so the box would stay 220px wide and the content would shrink to 156px. That is why most developers add * { box-sizing: border-box; }.
